# Fetch — MVP (v0.1)

## In
- [ ] JUCE VST3 shell: editor with chat panel + role selector
- [ ] Host sync: BPM + transport position from the host
- [ ] Local backend: LM Studio / Ollama chat endpoint
- [ ] Note-plan JSON schema + validation
- [ ] MIDI renderer: loop playback, bar-quantized swaps
- [ ] Roles: bass, chords, melody, drums (GM-mapped kit)
- [ ] Variation prompts (edit-the-plan deltas)
- [ ] Humanize slider (timing + velocity)
- [ ] Drag-out `.mid` export

## Later
- [ ] Cloud backends (Claude / OpenAI) with user-supplied key
- [ ] Key/scale detection from existing clips
- [ ] Audio-aware requests (analyse a dropped sample → matching parts)
- [ ] Phase 2: Max for Live companion, session control, arranging

## Done means
Load Fetch on a MIDI track, type "deep house bassline in F minor",
hear a locked, in-key loop inside two bars, type "darker", hear the
variation — all without leaving Live.
